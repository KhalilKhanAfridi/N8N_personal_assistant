# 🤝 Personal AI Assistant

A personal AI assistant built with **Streamlit** and **n8n**. It provides a single chat interface where I can interact with different personal automation tools.

## Features

* 📅 Manage calendar events and meetings
* 📧 Read, summarize, and reply to emails
* ✅ Create and manage tasks
* 📝 Take and manage notes
* 💰 Track expenses and budget
* 💬 Chat with the AI assistant through a Streamlit interface

## Tech Stack

* **Streamlit** — Frontend
* **n8n** — Automation and AI workflow
* **Python / Requests** — Webhook communication

## How It Works

The Streamlit app sends messages to an **n8n webhook**, where the automation workflow processes the request and performs the required action, such as creating a calendar event, managing emails, or creating a task.

## Deployment

The application is published on **Streamlit Community Cloud** and is currently built for **my personal use**.

## Status

🚀 **Live and actively used as a personal AI assistant.**
